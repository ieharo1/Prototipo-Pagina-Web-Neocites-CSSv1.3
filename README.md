Este es un clon profesional y optimizado del clásico **Tetris**, desarrollado desde cero utilizando únicamente tecnologías nativas de la web. Este proyecto demuestra el dominio de la lógica de programación, gestión de estado en tiempo real y manipulación avanzada del DOM y Canvas API sin depender de frameworks externos.

---

## 🚀 Características Principales

- **Zero-Dependency Architecture:** Implementación pura en Vanilla JavaScript (ES6+).
- **High Performance:** Motor de renderizado optimizado con `requestAnimationFrame` para 60 FPS estables.
- **Modern UI/UX:** Interfaz responsiva con estética *Cyberpunk/Dark Mode*, efectos de cristal (Glassmorphism) y animaciones fluidas.
- **Sistema de Niveles Progresivo:** La velocidad y dificultad aumentan dinámicamente según el desempeño del jugador.
- **Persistencia Local:** Seguimiento y guardado del récord personal mediante `localStorage`.
- **Diseño Responsive:** Adaptable a diferentes resoluciones (Desktop, Tablet).

## 🎮 Instrucciones de Juego

| Tecla | Acción |
| :--- | :--- |
| `←` `→` | Mover pieza lateralmente |
| `↑` | Rotar pieza (90°) |
| `↓` | Caída suave (Soft Drop) |
| `Espacio` | Caída instantánea (Hard Drop) |
| `P` | Pausar / Reanudar juego |

## 🛠️ Estructura Técnica

El código sigue una arquitectura modular y limpia para facilitar su mantenimiento:

- **`board.js`**: Gestión de la matriz del tablero y renderizado lógico.
- **`game.js`**: Núcleo del juego, gestión de estados, bucle principal y sistema de puntuación.
- **`pieces.js`**: Definiciones geométricas y propiedades de los Tetrominos.
- **`utils.js`**: Funciones matemáticas auxiliares, rotación de matrices y colisiones.
- **`main.js`**: Orquestador de eventos e inicialización del sistema.
